# 细粒度知识归属标注指南 v2

> 对应论文 5.2 节 / 实施计划 M3。标注对象：**作者 × 方法 × 角色** 四元组的参与关联 Z。
> 标注界面：`python pipeline/annotation_server.py --serve` 后访问 http://localhost:8765/?who=A（标注员 B 用 ?who=B）
> v2 修订说明：基于试点批（5 篇、312 单元、κ=0.136）的分歧分析，修订三处规则（§2.1 证据优先级、§3 边界案例第 2/3/7 条为新增或改写），已经项目负责人在校准会上裁决确认。

## 1. 标注任务

对每篇论文，界面给出：论文标题、摘要、Methods 全文（折叠）、每个候选方法实体的原文上下文（高亮），以及「作者 × 方法」判定矩阵。

对每个单元格做三态判定：

- **是（1）**：有证据支持该作者参与了该方法的相关工作（证据定义见 §2）；
- **否（0）**：证据表明该作者未参与（如仅承担 Supervision/Funding 等非方法角色，且无反证）；
- **不确定（2）**：证据不足以判断，或证据相互矛盾。

判定为「是」的单元格，需进一步勾选该作者**以什么角色**参与（候选列表只含该作者在本文中声明过的 CRediT 角色）。

## 2. 判定依据（按优先级）

1. **正文或附属信息中的直接点名证据**【v2 提升为最高优先级】：Methods/致谢/代码仓库路径等直接指名某位作者做了某项工作（例：代码仓库 URL 含作者姓氏、"X.Y. performed the simulations"）；
2. **贡献声明 / CRediT 角色**（结合作者声明的角色组合与实体类型的语义匹配）；
3. **唯一角色持有者规则**【v2 新增】：当某项方法类角色（methodology / software / formal-analysis 等）在全体作者中**只有一位**声明者，且该角色与实体类型语义匹配时，可判定该作者「是」，无需正文点名；
4. **作者专长弱推断**（慎用）：仅当以上都没有时可参考，此时只能标「不确定」，不能标「是」。

**证据等级记录【v2.1 新增，强制】**：每条 z=1 的判定必须同时记录证据等级 `ev`，取值：
- `direct`：§2.1 直接点名证据；
- `unique_holder`：§2.3 唯一角色持有者规则；
- `declared_match`：§2.2 声明角色与实体类型匹配（含流水线规则 §3-2）；
- `weak`：其他弱证据（须在备注中说明）。

该字段用于评测集分层：论文将分别在「硬证据样本」（direct + unique_holder）与「规则推断样本」（declared_match + weak）上报告归属精度，避免金标质量被单一证据来源主导。

## 3. 判定规则与边界案例

| # | 情形 | 判定 |
|---|---|---|
| 1 | 作者声明了 Methodology，论文只有一个方法 | 「是」+ 勾选 Methodology |
| 2 | **流水线论文**【v2 改写】：候选实体是同一方法框架的组件/步骤（如 CNN 模型的卷积层、池化层；同一估计模型的多个分布组件） | 声明 Methodology / Software 等匹配角色的作者，对核心组件标「是」（多人可共享，不互斥）；**不因“无法区分组件”而标不确定** |
| 3 | **多独立方法论文**【v2 改写】：论文确有多个相互独立的方法，且证据无法对号到具体作者 | 标「不确定」，不猜 |
| 4 | 通讯作者只声明 Supervision / Funding / Resources / Writing 等非方法角色 | 方法格子一律「否」，除非正文另有证据 |
| 5 | 「是」但角色无法细分 | 标「是」+ 勾选最匹配的一个角色 |
| 6 | 方法实体本身是背景提及（reviewed） | 所有作者标「否」 |
| 7 | **作者无任何声明角色（declared_roles 为空）**【v2 新增】 | 标「不确定」（数据缺口不等于无贡献），除非有直接证据证明未参与 |
| 8 | 多人共同承担同一方法 | 每人都可标「是」，**不要求互斥** |
| 9 | 作者仅有支持性角色（data-curation / investigation），确认实质性参与但无法绑定到具体方法实体 | 标「不确定」 |

## 4. 质量控制

- 两名标注员独立标注同一批论文，**过程中不得交流具体判定，不得查看对方结果**；
- 不允许查看任何模型输出或 LLM 锚点（界面已不包含此类信息）；
- 一致性指标：Cohen's κ（目标 ≥ 0.7）；分歧样本集中协商裁决，裁决记录附在数据中；
- 指南修订历史：v1（初版）→ v2（试点校准后修订，§2.1、§2.3、§3-2/3/7）。

## 5. 工作量参考

- 每篇约 50 个判定单元，预计 5–10 分钟/篇；
- 试点批 5 篇已完成校准（v2）；正式批 45 篇 × 2 人，可分多次完成（界面自动记录进度）。
