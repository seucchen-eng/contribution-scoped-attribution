# Contribution-Statement-Supervised Fine-Grained Knowledge Attribution of Authors for Task-Driven Collaborator Recommendation

Reproducibility package for the paper submitted to *Expert Systems* (Wiley).

The project learns **author–method–role participation associations** $\hat{Z}_{apkr}$ under hierarchical weak supervision (coarse CRediT contribution statements + fine-grained full-text anchors + author-history priors), and injects the learned attribution into task-driven collaborator ranking via a role-matching profile $P_6(r \mid a, k)$.

## Repository layout

| Path | Content |
|---|---|
| `code/` | All pipeline and experiment scripts (Python) |
| `annotation/` | Annotation guideline (v1/v2, Chinese), candidate task lists, dual-annotator raw labels, adjudicated gold standard (3,306 cells), frozen train/test split |
| `results/` | Task A/B result tables (JSON/TXT), per-query metrics (`taskb_perq_v3.npz`), baseline score dumps, main model checkpoint (`ckpt_b6_main.pt`, ~240 KB), case-study figure |
| `data_lists/` | Corpus paper lists (500 training-period + 250 evaluation-period PLOS Computational Biology papers) and the Task B query set (`taskb_queries_v3.jsonl.gz`, 20,852 queries) |

Large intermediate artefacts (raw JATS XML, full-text pickles, OpenAlex author histories, TF-IDF feature matrices) are **not** included for size reasons; they are regenerated by the pipeline below from public sources (PLOS and OpenAlex).

## Reproduction pipeline

Run from a working directory; scripts read/write under `data/processed/` relative to the repo layout used in the paper. High-level order (each script has a docstring with details):

1. **Corpus acquisition**
   - `fetch_plos.py` — download full texts + contribution statements for the 750 corpus DOIs (`data_lists/corpus_papers*.csv`) from PLOS (JATS XML)
   - `fetch_openalex.py` — author disambiguation + publication histories from OpenAlex
2. **Evidence extraction**
   - `extract_methods.py` — LLM extraction of method-entity mentions (span-verified)
   - `link_entities.py` — entity linking into the shared method-entity space
   - `build_c_apr.py` — contribution-statement parsing → coarse role labels $C_{apr}$
   - `compute_priors.py` — author-history priors $\pi_{ak}$ (Eq. 1)
   - `map_entities_post.py` + `expand_priors_post.py` — cross-journal history matching for evaluation-period new entities (cold-start extension)
3. **Gold standard**
   - `freeze_gold.py` — build the adjudicated gold standard and the frozen 8:2 split (`annotation/gold_standard.jsonl`, `gold_split.json`; already provided)
4. **Feature construction** — `features.py` (TF-IDF 512-d text encoder; SPECTER2 comparison: `pilot_specter.py`)
5. **Task A (attribution)**
   - `run_b6.py` — the proposed contribution-constrained attribution layer
   - `run_b3.py`, `run_b4_b5.py` — HeteAlloc+LLM / role-feature GNN / generic MIL baselines
   - `run_ablation.py` — ablation ladder and constraint-violation variants
   - `run_noise.py` — anchor-noise sensitivity (10% / 20% label flips)
   - `evaluate.py` — metrics (AUPRC, P/R/F1, ECE)
6. **Task B (task-driven recommendation)**
   - `build_queries_v3.py` — multi-positive temporal query construction
   - `run_b1_b2.py`, `run_taskb.py`, `run_taskb_full.py` — scoring of all six methods on the main set and the full set incl. the method-cold-start subset
   - `run_taskb_seed.py`, `run_taskb_permtest.py` — 5-seed robustness and paired permutation tests with Holm correction
7. **Case study** — `case_study_en.py` reproduces the five-panel heatmap (Figure 2 of the paper)

## Annotation transparency

The fine-grained ground truth (3,306 author × method cells on 94 papers) was produced by **two independent annotators** following `annotation/guideline_v2_zh.md`, with disagreements resolved by a third round of independent in-depth adjudication, and **final review and confirmation by the authors** (raw dual annotations are included for full transparency). Inter-annotator agreement: raw agreement 0.964, Cohen's κ = 0.938.
